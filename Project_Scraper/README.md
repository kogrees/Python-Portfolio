# Basic Job Web Scraper

A basic Python web scraping project created to learn and practice **BeautifulSoup**.

The project extracts job listing information from a webpage and saves the collected data into a CSV file.

## 🛠️ Technologies Used

- Python
- BeautifulSoup
- Requests
- Pandas

## 📌 What I Learned

This project helped me understand the basics of:

- Sending HTTP requests using `Requests`
- Parsing HTML using `BeautifulSoup`
- Finding elements using HTML tags and classes
- Extracting text and attributes from HTML
- Storing scraped data in a list
- Creating a Pandas DataFrame
- Basic data cleaning and transformation
- Exporting data to CSV
